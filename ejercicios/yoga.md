# Ejercicio Yoga

## Descripción
El yoga combina respiración, posturas y concentración para mejorar el bienestar físico y mental.

## Beneficios
- Mejora flexibilidad.
- Reduce estrés.
- Favorece equilibrio corporal.

## Instrucciones
1. Busca un espacio tranquilo.
2. Realiza posturas lentamente.
3. Mantén respiración constante.
